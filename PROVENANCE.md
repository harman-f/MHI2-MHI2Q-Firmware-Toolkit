# Provenance

This repository is maintained as a standalone firmware-extraction and analysis toolkit.

- Included: project-authored Python/Bash extraction logic, parser tests, image-format observations, metadata/repack helpers, external-tool documentation.
- Excluded: firmware archives, extracted proprietary filesystems, credentials/private keys, machine-specific paths, generated unit data, and third-party code that is not intentionally redistributed under a compatible license.
- Integration validation is summarized in `reports/MULTI_FIRMWARE_VALIDATION_2026-09-28.md`; raw firmware archives, complete extracted trees, and reverse-engineering project databases are not stored in this repository.
- Third-party provenance and license boundaries are documented in `DEPENDENCIES.md` and `dependencies/THIRD_PARTY_NOTICES.md`.

Commit metadata for the publication branch uses the `harman-f` GitHub identity and GitHub noreply addressing.
